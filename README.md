# 📉 그가 샀습니다

가상 자금으로 즐기는 **실시간 주식 모의 투자** 서비스입니다. 돈을 다 잃으면(파산) 주가 맞히기 미니게임과 월급으로 재기해야 합니다.

- **모든 종목 매매**: 어떤 종목이든 사고팔 수 있고 여러 종목을 함께 보유할 수 있습니다(매수로는 최대 20종목).
- **실시간 시세는 보고 있는 종목만**: 트래픽을 줄이려고 지금 화면에 띄운 종목 1개만 실시간으로 받습니다. 보유 종목 평가는 1분 캐시 시세로 합니다.
- **실시간 시세**: 한국투자증권(KIS) Open API 실시간 체결가(H0STCNT0)를 서버가 받아 브라우저로 중계합니다.
- **파산과 재기**: 총자산(현금 + 보유 주식 전체 평가액)이 **10만원 미만**이 되면 파산합니다. 보유 주식은 강제 청산되고 매매가 잠깁니다. 미니게임 상금과 월급(매달 100만원)으로 **현금 100만원 이상**을 모으면 재기합니다.
- **로그인/로그아웃**: 이메일과 비밀번호로 가입합니다. 세션은 httpOnly 쿠키로 관리합니다.
- **개미 광장(유저 간 상호작용)**: 블라인드 박스 교환, 기습 털기, 1:1 수익률 맞짱
- **숨겨진 배지와 프로필**: 특정 조건을 달성하면 배지(45종)를 얻고, 하나를 골라 닉네임 옆에 달 수 있습니다. 프로필에는 내가 공개하기로 한 항목만 보입니다.

## 구조

모든 구성 요소가 Cloudflare 한 곳에서 돌아가며, 무료 플랜으로 운영할 수 있습니다.

```
브라우저 (React SPA)
   │  REST /api/*            WebSocket /api/ws (종목 구독/해제)
   ▼                               │
Cloudflare Worker (Hono) ──────────┤
   │  D1 (SQLite): 회원·세션·잔고·주문·게임
   │                               ▼
   │                   PriceHub (Durable Object, 서비스 전체 1개)
   │                     · 브라우저 WebSocket 전부 수용 (Hibernation)
   │                     · 구독 종목의 합집합만 KIS에 등록 (서버 측 팬아웃)
   │                     · 종목당 1초 1회로 묶어서 전송
   │                               │ ws://ops.koreainvestment.com:21000
   └─ PasswordHasher (DO)          ▼
      비밀번호 해시 전용        한국투자증권 Open API
```

### 미니게임: 주가 맞히기 (파산했을 때만)
실제 과거 일봉으로 문제를 만듭니다. 정답은 서버만 알고 있어서 클라이언트를 조작해 점수를 만들 수 없습니다.

| 난이도 | 문제 | 선택지 | 정답 상금 |
| --- | --- | --- | --- |
| 쉬움 | 인기 종목과 실제 날짜를 공개합니다. 20거래일 동안 **올랐을까, 내렸을까?** | 2 | 100,000원 |
| 보통 | 종목과 날짜를 숨깁니다. **5거래일 뒤** 종가가 +3% 이상 / ±3% 이내 / −3% 이하 중 어디일까? | 3 | 300,000원 |
| 어려움 | 종목과 날짜를 숨깁니다. **다음 날** 등락률이 +2%↑ / 0~+2% / −2%~0 / −2%↓ 중 어디일까? | 4 | 600,000원 |

- 하이리스크 하이리턴: 어려울수록 맞히기 어렵지만 상금이 큽니다. 틀리면 상금은 없고 기회만 사라집니다.
- **하루 3회, 한 달 10회**까지 할 수 있습니다. 문제를 받는 순간 1회가 차감되고, 2분 안에 답해야 합니다.

### 배지 · 프로필 · 닉네임
- 배지는 45종이고 **획득 조건은 비공개**입니다. 조건은 서버(`worker/badges.ts`)에만 있습니다.
  - 본인: 획득한 배지만 이름·설명·조건을 볼 수 있고, 아직 얻지 못한 배지는 개수만 보입니다.
  - 다른 사람: 배지 이름·등급·한 줄 설명만 보이고 조건은 볼 수 없습니다.
- 등급은 일반 · 희귀 · 영웅 · 전설 네 가지입니다. 획득한 배지 하나를 **대표 배지**로 골라 닉네임 옆에 표시합니다.
- 가입하면 먼저 **프로필 공개 범위**를 정합니다. 기본값은 **모두 비공개**입니다.
  - 설정 항목: 획득 배지, 보유 종목(이름만), 파산 횟수, 총자산, 보유 종목 수익률, 최근 매매(금액 제외)
  - 파산 명예의 전당에는 파산 횟수를 공개한 사람만 오릅니다.
- **닉네임 변경은 3일(72시간)에 한 번만** 할 수 있습니다.
  - 기준은 마지막으로 변경한 시각입니다.
  - 가입할 때 정한 닉네임은 변경 횟수에 포함되지 않습니다.
  - 닉네임은 2~16자의 한글·영문·숫자·밑줄(_)만 쓸 수 있습니다.

### 🐜 개미 광장 (유저 간 상호작용)
상대가 프로필의 **받기 설정**에서 허용한 상호작용만 걸 수 있습니다(기본: 모두 거부).
- 종류별로 하루 1번씩 걸 수 있습니다.
- 받은 요청은 24시간 안에 응답하지 않으면 만료되고, 맡겨 둔 판돈은 돌려받습니다.
- 파산 상태에서는 걸 수도, 받을 수도 없습니다.

| 이름 | 방식 | 판돈 |
| --- | --- | --- |
| 🎁 블라인드 박스 교환 | 내 주식 1주를 상자에 넣어 보냅니다. 상대에게는 종목명 대신 **가격대**(예: 5만~10만원대)만 보입니다. 상대가 이름을 가린 1주를 넣으면 맞교환하고, 받은 주식의 단가는 교환 시점의 현재가로 계산합니다. | 없음 |
| 🥷 기습 털기 | 주가 맞히기(보통 난이도) 한 문제로 결투합니다. 건 사람만 맞히면 **상대 주식 1주를 무작위로** 털어 오고, 상대만 맞히면 판돈을 상대에게 줍니다. 둘 다 맞히거나 둘 다 틀리면 무승부입니다. | 10만~100만원 |
| 🥊 1:1 수익률 맞짱 | 각자 종목 하나를 고르고(건 사람의 종목은 수락 전까지 비공개) **7일 뒤 15:30** 종가 기준 수익률이 높은 쪽이 판돈을 모두 가져갑니다. 동시에 3개까지 진행할 수 있습니다. | 10만~100만원 |

준비 중(화면에 제목과 설명만 표시): 십시일반(월급 몰아주기), 조의금, 그가 샀다! 알림(팔로우), 예언하기, 리액션, 투자 동아리

돈과 주식이 오가는 처리는 D1 batch와 `tx_guard` 테이블로 원자적으로 실행합니다. 조건이 하나라도 어긋나면(예: 교환하려던 주식을 그사이 팔았음) 전체가 롤백됩니다.

### 🛡️ 관리자
- 관리자는 **화면에서 지정할 수 없습니다.** 저장소에 쓰기 권한이 있는 사람만 GitHub Actions로 지정할 수 있습니다.
  1. 먼저 사이트에 일반 회원으로 가입합니다.
  2. GitHub 저장소 *Actions → 관리자 지정 → Run workflow*에서 가입한 이메일을 넣고 `grant`로 실행합니다. 해제할 때는 `revoke`로 실행합니다.
  3. 다시 로그인하면 상단에 **관리** 메뉴가 생깁니다.
  - 회원가입에 이메일 인증이 없어서, "이 이메일이면 관리자" 같은 설정은 다른 사람이 그 이메일로 먼저 가입하면 권한을 가로챌 수 있습니다. 그래서 이 방식을 씁니다.
- 관리자만 `/admin` 페이지와 `/api/admin/*`를 쓸 수 있습니다. 서버가 매 요청마다 DB의 권한을 확인합니다.
  - **닉네임 강제 변경**: 비워 두면 `개미12345` 같은 이름으로 바꿉니다. 3일 제한과 무관하고, 바뀐 사람은 바로 다시 바꿀 수 있습니다.
  - **계정 정지 / 해제**: 사유는 필수입니다. 정지하면 로그인 중인 세션이 끊기고, 다시 로그인하면 정지 사유가 보입니다. 정지된 계정은 프로필, 명예의 전당, 개미 광장에서 보이지 않습니다. 관리자 계정은 정지할 수 없습니다.
  - 모든 조치는 **조치 기록**에 남습니다.
- 로컬에서 관리자를 지정하려면 다음 명령을 실행합니다.
  ```bash
  npx wrangler d1 execute DB --local --command "UPDATE users SET role = 'admin' WHERE email = '내이메일'"
  ```

## 배포 (GitHub → Cloudflare)

`main` 브랜치에 push하면 `.github/workflows/deploy.yml`이 다음을 자동으로 처리합니다.

1. D1 데이터베이스 생성 (없을 때만)
2. 마이그레이션 적용
3. Worker 배포
4. KIS 시크릿 등록

### 처음 한 번만 설정
1. **Cloudflare 계정**을 만들고, 대시보드의 *Workers & Pages*에 한 번 들어가서 `workers.dev` 서브도메인을 등록합니다.
2. **API 토큰 발급**: Cloudflare 대시보드 → *My Profile → API Tokens → Create Token*
   - 템플릿 *Edit Cloudflare Workers*를 고르고 권한에 **Account · D1 · Edit**를 추가합니다.
3. **Account ID 확인**: *Workers & Pages* 화면 오른쪽에 있습니다.
4. GitHub 저장소 *Settings → Secrets and variables → Actions*에 다음을 등록합니다.

   | 이름 | 필수 | 내용 |
   | --- | --- | --- |
   | `CLOUDFLARE_API_TOKEN` | ✅ | 2번의 토큰 |
   | `CLOUDFLARE_ACCOUNT_ID` | ✅ | 3번의 ID |
   | `KIS_APP_KEY` | 선택 | 한국투자증권 앱키 (없으면 모의 시세) |
   | `KIS_APP_SECRET` | 선택 | 한국투자증권 앱시크릿 |

5. `main`에 push하거나 *Actions → Deploy to Cloudflare → Run workflow*를 실행합니다. 배포 주소는 `https://he-bought-dump-it.<서브도메인>.workers.dev`입니다.

### Cloudflare Workers Builds(대시보드의 Git 연동)를 켠 경우
GitHub Actions(`deploy.yml`)가 이미 마이그레이션과 배포를 처리하므로 **Workers Builds는 꺼 두는 것을 권장합니다.**
- 끄는 곳: Cloudflare 대시보드 → Workers & Pages → he-bought-dump-it → Settings → Build → Disconnect
- 켜 둔다면 배포가 두 번 일어납니다. 또 Workers Builds는 D1 마이그레이션을 적용하지 않아서, 새 마이그레이션이 들어간 변경은 잠깐 오류가 날 수 있습니다.
  - 그래서 Workers Builds의 Deploy command는 `npm run deploy`(마이그레이션 적용 → 배포)로 바꿔 주세요.
- 저장소 설정은 어느 쪽으로 배포해도 동작하게 해 두었습니다.
  - `wrangler.jsonc`에 실제 D1 ID가 들어 있습니다.
  - `build.command`로 배포 전에 프론트엔드를 자동으로 빌드합니다.

### 한국투자증권 Open API 키
[KIS Developers](https://apiportal.koreainvestment.com)에서 계좌를 연결하고 앱키와 앱시크릿을 발급받습니다. 연동 방식은 공식 샘플 [koreainvestment/open-trading-api](https://github.com/koreainvestment/open-trading-api)를 따릅니다.

- 모의투자용 키라면 `wrangler.jsonc`의 `KIS_ENV`를 `demo`로 바꿉니다.
- 접근 토큰은 재발급할 때마다 알림톡이 가기 때문에, 서버가 Durable Object 저장소에 캐시해서 하루 1번만 발급받습니다.

## 알아둘 점
- **KIS 실시간 연결 검증 필요**: KIS 웹소켓은 비표준 포트(`:21000`)를 씁니다. Workers는 `compatibility_date` 2024-09-02 이후부터 사용자 지정 포트를 허용하므로 동작할 것으로 예상합니다. 다만 실제 키로 연결 테스트를 하지 못했습니다. 배포 후 실시간 시세가 안 들어오면 Cloudflare 대시보드의 Worker 로그(`KIS realtime connect failed`)를 확인하세요. 실시간 연결이 안 되는 동안에도 30초마다 REST 현재가로 갱신합니다.
- **종목 목록**: 검색용 종목은 주요 125개(`migrations/0002_seed_stocks.sql`)입니다. 전체 종목이 필요하면 KIS 종목 마스터 파일(`kospi_code.mst`, `kosdaq_code.mst`)로 `stocks` 테이블을 채우면 됩니다.
- 장 시작일(1월 첫 거래일)이나 수능일처럼 개장 시간이 늦춰지는 날은 반영하지 않았습니다.
