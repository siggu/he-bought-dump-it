# 그가 샀습니다 — 서비스 사양

> 가상 자금으로 즐기는 실시간 주식 모의 투자. 파산하면 게임으로 다시 일어선다.

구현 세부와 배포 방법은 루트의 README.md를 참고하세요. 이 문서는 확정된 규칙을 정리합니다.

## 1. 확정된 결정 사항

| 항목 | 결정 |
| --- | --- |
| 시세 데이터 | 실제 국내 주식 (한국투자증권 Open API). 키가 없으면 모의 시세로 대체 |
| 매매 | **모든 종목 매매 가능**, 여러 종목 보유 가능 (매수로는 최대 20종목) |
| 실시간 시세 | **지금 화면에서 보고 있는 종목 1개만** 실시간 수신 (트래픽 절감). 보유 종목 평가는 1분 캐시 시세 |
| 파산 기준 | **총자산(현금 + 보유 주식 전체 평가액) < 100,000원** |
| 재기 기준 | 파산 상태에서 **현금 ≥ 1,000,000원** |
| 월급 | 매달(KST) 1회 1,000,000원 수령 |
| 미니게임 | 파산자 전용 주가 맞히기. 난이도 3단계(쉬움 10만 / 보통 30만 / 어려움 60만), 하루 3회·한 달 10회 |
| 배지 | 숨겨진 배지 45종. 조건은 비공개, 본인은 획득한 배지의 조건과 미획득 배지 개수를 볼 수 있음 |
| 프로필 공개 | 가입 직후 공개 범위를 설정. 기본값은 모두 비공개 |
| 닉네임 변경 | **3일(72시간)에 1회**. 기준은 마지막 변경 시각, 가입 시 닉네임은 변경 횟수에 포함하지 않음 |
| 상호작용 | 블라인드 박스 교환 / 기습 털기 / 1:1 수익률 맞짱. 받는 사람이 허용한 것만, 종류별 하루 1회 |
| 관리자 | GitHub Actions로만 지정. 닉네임 강제 변경, 계정 정지/해제, 관리 기록 |
| 인프라 | Cloudflare Workers + Durable Objects + D1, GitHub Actions로 자동 배포 |

## 2. 파산 규칙 (상세)

1. 계좌를 조회하거나 주문할 때마다 `총자산 = 현금 + Σ(보유 수량 × 현재가)`를 계산한다.
2. `총자산 < 100,000원`이면 파산한다.
   - 보유 주식을 모두 현재가로 강제 매도한다(수수료·거래세 적용). 거래 내역에는 "강제청산"으로 남는다.
   - 매매와 상호작용이 잠긴다. 누적 파산 횟수가 1 늘어난다.
3. 보유 종목 중 하나라도 시세를 불러오지 못하면 그 순간에는 판정하지 않는다(시세 장애로 인한 오판 방지).
4. 파산 상태에서 현금이 1,000,000원 이상이 되면(월급, 미니게임 상금) 재기한다.

## 3. 사용자 흐름

```
회원가입 ─▶ 프로필 공개 범위 설정(기본 전부 비공개) ─▶ 초기 자금 10,000,000원
   │
   ▼
[내 계좌] 총자산 · 보유 종목 · 파산 기준 · 월급 · 개미 광장
   │ 종목 검색/선택
   ▼
[종목 화면] 실시간 차트(이 종목만 실시간) + 매수/매도
   │ 총자산 < 10만원
   ▼
[파산] 강제 청산 · 매매 잠금 ─▶ 미니게임 / 월급 ─▶ 현금 100만원 이상 ─▶ 재기
```

## 4. 상호작용 (개미 광장)

| 이름 | 방식 | 판돈 |
| --- | --- | --- |
| 블라인드 박스 교환 | 서로 보유 주식 1주를 종목명을 가린 채(가격대만 공개) 맞교환한다. 받은 주식의 단가는 교환 시점 현재가로 계산한다. | 없음 |
| 기습 털기 | 같은 주가 맞히기 문제로 결투한다. 건 사람만 맞히면 상대 주식 1주를 무작위로 가져오고, 상대만 맞히면 판돈을 상대에게 준다. 나머지는 무승부. | 10만~100만원 |
| 1:1 수익률 맞짱 | 각자 종목 1개를 골라 7일 뒤 15:30 종가 기준 수익률이 높은 쪽이 판돈을 모두 가져간다. 동시에 3개까지 진행할 수 있다. | 10만~100만원 |

- 받는 사람이 프로필에서 허용한 상호작용만 걸 수 있다(기본: 모두 거부).
- 종류별로 하루 1번씩 걸 수 있다. 응답 기한은 24시간이며, 만료·거절·취소되면 판돈을 돌려준다.
- 파산한 사람은 걸 수도, 받을 수도 없다.
- 준비 중(제목과 설명만 표시): 십시일반, 조의금, 그가 샀다! 알림, 예언하기, 리액션, 투자 동아리

## 5. 관리자

- 관리자는 화면에서 지정할 수 없다. 저장소 관리자만 실행할 수 있는 GitHub Actions 워크플로(`관리자 지정`)로 이메일을 지정한다.
- 관리자만 `/admin` 페이지와 `/api/admin/*` API를 쓸 수 있다.
  - 닉네임 강제 변경: 3일 제한과 무관하게 바꾼다. 바뀐 사람은 바로 다시 바꿀 수 있다.
  - 계정 정지/해제: 사유를 기록한다. 정지된 계정은 로그인과 모든 기능이 막힌다.
  - 모든 조치는 관리 기록(admin_actions)에 남는다.

## 6. 앞으로의 아이디어

- 시즌제: 한 달 단위로 자산을 초기화하고 시즌 랭킹을 매긴다.
- 지정가 주문, 가격 알림, 매매 일지(차트 위 메모)
- 전체 종목 마스터 연동 (KIS `kospi_code.mst` / `kosdaq_code.mst`)
